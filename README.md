# Tomelet downloads

Official downloads of [Tomelet](https://tomelet.app), the ebook reader that keeps the publisher's fonts and layout,
lets you write on any page, and syncs your library with end-to-end encryption.

## Tomelet 1.0.0

Get the latest version from the [1.0.0 release page](https://github.com/tomelet-org/tomelet-downloads/releases/tag/app-v1.0.0%2B31).

| Platform | Download | Getting started |
|---|---|---|
| Android | `tomelet-1.0.0-android.apk` | Open the APK to install. Android 7.0 or later. |
| macOS | `tomelet-1.0.0-macos.dmg` | Drag Tomelet into Applications. macOS 12 or later. |
| Windows | `tomelet-1.0.0-windows-x64.zip` | Unzip it anywhere and run `tomelet.exe`. Windows 10 or later. |
| Linux | `tomelet-1.0.0-linux-x86_64.tar.gz` | Unpack it and run `bundle/tomelet`. |

iPhone and iPad are coming soon.

Every release includes a `SHA256SUMS` file, so you can check your download.

Earlier `app-v0.x` releases were test builds. For the best experience, use 1.0.0.
