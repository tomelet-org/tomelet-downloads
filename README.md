# Tomelet downloads

Official downloadable builds of Tomelet.

Use the [Releases](https://github.com/tomelet-org/tomelet-downloads/releases) page for versioned downloads. Every release includes a `SHA256SUMS` file so the downloaded bytes can be verified.

Android preview APKs are debug-signed for sideload testing. They are not Play Store builds, and a later store-signed version may require uninstalling the preview first. Each release records the private source revision and build configuration used to produce it.
